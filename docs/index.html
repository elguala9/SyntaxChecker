A stray comma in JSON. A duplicate key in TOML. An unbalanced XML tag. SyntaxChecker answers one question fast — is this file valid? — across dozens of formats, as a CLI and an MCP server for AI assistants.

Built to be small, fast, and honest

No runtime, no native libraries, no surprises — just a single static binary that does one thing well.

🦫

Single static binary

Pure-Go, CGO_ENABLED=0, -trimpath, stripped symbols. Drop it anywhere — no install, no dependencies, no "works on my machine."

🧠

Beyond well-formedness

JSON Schema validation (drafts up to 2020-12) for JSON & YAML, DTD validation for XML, duplicate-key detection, and a strict mode for the pedantic rules.

🤖

Speaks to AI assistants

Ships as an MCP server exposing check_syntax, so Claude Code & Claude Desktop can validate files mid-workflow. One-command plugin install.

🎯

One uniform contract

30+ wildly different grammars report through the same result shape and exit codes (0 valid, 1 errors, 2 internal) — scriptable everywhere.

⚡

Fast & transparent

Most parsers run in under 20 ms. Where there's a trade-off (WASM Postgres, ANTLR for T-SQL/Oracle), it's documented — not hidden.

🧪

Tested like it matters

A sample suite pairs valid files with deliberately broken ones. If a parser stops catching a real error, CI breaks. Releases are built & published automatically.

Install it your way

Package manager, AI plugin, prebuilt binary, or build from source.

🪟 winget (Windows)

Installs both binaries and registers PATH aliases.

winget install Parresia.SyntaxChecker

🤖 Claude Code plugin

Binaries auto-downloaded & SHA-256 verified on first use.

/plugin marketplace add elguala9/SyntaxChecker
/plugin install syntaxchecker

⬇️ Prebuilt binary

Linux x64 & Windows x64 archives with checksums.

Download the latest release 
github.com/elguala9/SyntaxChecker/releases/latest

🛠️ Build from source

Requires Go 1.22+ and Mage.

git clone https://github.com/elguala9/SyntaxChecker
cd SyntaxChecker
mage build

Dead-simple CLI

One flag set, every format. Auto-detection by extension, or force a type.

syntax-checker -f config.json
syntax-checker -f query.sql -t sql:mysql
syntax-checker -f data.json --strict -o json-pretty
syntax-checker -f data.json --schema schema.json
syntax-checker -f compose.yaml -t compose
