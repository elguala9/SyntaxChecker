# SyntaxChecker — project website

Static landing page served via **GitHub Pages**.

- `index.html` — single-file site (embedded CSS/JS, no build step).
- `.nojekyll` — disables Jekyll processing so files are served as-is.

## Enable GitHub Pages

1. Push this `docs/` folder to the default branch.
2. GitHub → **Settings → Pages**.
3. **Source:** *Deploy from a branch*.
4. **Branch:** `master` (or your default) · **Folder:** `/docs`.
5. Save. The site goes live at `https://elguala9.github.io/SyntaxChecker/`.

## Editing

It's plain HTML — open `index.html` in a browser to preview, edit, refresh.
No dependencies, no toolchain.
